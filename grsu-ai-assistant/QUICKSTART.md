# Быстрый старт

## Подготовка окружения

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Скопируйте шаблон конфигурации:
```bash
cp .env.example .env
```

3. Укажите свои настройки в `.env` файле:
   - `OPENAI_API_KEY` - ваш API ключ от OpenAI (не обязательно если используете локальные модели)

## Запуск приложения

1. Запустите веб-интерфейс:
```bash
streamlit run src/app.py
```

2. Откройте браузер по адресу http://localhost:8501

## Автозапуск идеи для популярного продукта

Если нужно быстро выбрать рыночное направление и получить готовый план запуска:

```bash
streamlit run src/market_launchpad.py
```

Инструмент выдаёт:
- рейтинг ниш с объяснимыми оценками,
- 30-дневный roadmap,
- sprint на первые 48 часов,
- файл `launch_brief.md` для скачивания.

## Загрузка документов

1. В интерфейсе нажмите "Upload Documents"
2. Выберите PDF, DOCX или TXT файлы с ГОСТ, СТБ, СНиП
3. Документы будут автоматически проиндексированы

## Использование

1. Введите вопрос в поле ввода (например: "Какие требования к оформлению чертежей по ГОСТ 21.1101?")
2. Получите ответ с указанием источника
